## P0 — crash / connectivity / security

**1. [bugfixer] Cannot connect to unified :443 hub — no SSL context + targets retired :8765.**
`bugfixer/hub_agent.py:371` `websockets.connect()` passes no `ssl=`; a `wss://` connect to the self-signed hub → `CERTIFICATE_VERIFY_FAILED`. Separately `main.py:2927` derives `ws://host:8765` (the retired bare listener). Fix: pass `ssl._create_unverified_context()` for wss (honor `LM_HUB_TLS_VERIFY`/`LM_HUB_CA_CERT`), and target `wss://host:443/ws/spoke`. Mirrors pxmx fbed823 / `BaseControlPlane._client_ssl_ctx`.

**2. [lm core] Hub zombie-connection `finally` wipes the LIVE replacement's routing state.**
`core/src/main.py:2326-2340` — the `active_connections` delete (2323-2325) is `is websocket`-guarded, but the sibling cleanup (pops `spoke_module_types`, `spoke_parent_map`, `spoke_authenticated`, `_unauth_warned_spokes`, evicts hosted agents) is guarded only by `if spoke_id:`. After an evicting reconnect (B replaces zombie A), A's `finally` deletes **B's** registry state → `get_spoke_by_type` misses, agent relay breaks, `spoke_authenticated=False` lets a later pending conn wrongly evict the live one. Same cs-spoke-1 zombie class; guard just wasn't extended. Fix: gate 2326-2340 on `self.active_connections.get(spoke_id) is websocket`.

**3. [lm WebUI] Stored XSS — spoke/tenant data interpolated raw into `innerHTML`.**
`WebUI/main.js`: opnsense aliases/NAT/rules table `7018-7030` (twin at 7220 IS escaped — drift), DNS records `8994-8998` (a TXT value `<img onerror=…>` fires), NetBox tables `8090-8178`, VM-detail firewall rules `6858-6862` + `err.message` `6867`, Proxmox node table `7812-7813`, usernames `6092/6148/8267/10289`. Fix: wrap each `${…}` in `escapeHtml(…)`. (`sim-views.js` is clean.)

**4. [lm WebUI] `onclick="fn('${escapeHtml(x)}')"` — JS-string-context XSS/breakage.**
`main.js:7138-7139` (`pollNwDevice`/`showNwConfigModal`), `2596`, `5033-5034`: browser HTML-decodes `&#39;`→`'` before JS parses, so `escapeHtml` doesn't neutralize `'` here (`Bob's switch` → dead button; `');alert(1)//` executes). `escJs`-only sites `7411-7416,7487` don't escape `"`. Fix: two-layer escape (`.replace(/'/g,"\\'")` then `csEscape`) as in `sim-views.js:3495`, or `data-*` + `addEventListener`.

**5. [ldap] DN injection + cleartext `userPassword`.**
`ldap_manager.py` RDNs f-string-built without `ldap.dn.escape_dn_chars` (`:33,61,98,162,192,206`) — username `foo,ou=admins` reparents the entry (spoke binds as admin). `create_user` (`:63-70`) sets raw `userPassword` via `add_s` (slapd doesn't auto-hash on plain add; no `olcPasswordHash` configured) → cleartext at rest. Fix: escape every RDN value; hash `{SSHA}` before add or create-then-`passwd_s`.

**6. [installers] Fresh-deploy breakers (cross-poll).**
- Missing `mkdir -p /var/log/lm` before the `append:` unit → 206/EXEC on a clean box: `cppm/install.sh:104`, `nw/install_nw.sh:119`, `opnsense/install_opnsense.sh:118`.
- Default `HUB_URL="ws://localhost:8765"` (retired port) — dials dead listener if `--hub` omitted: `cppm/install.sh:5`, `netbox/install.sh:23`, `nw/install_nw.sh:5`. Fix: default to `auto` (like ldap/le/opnsense).

## P1 — silent-wrong / data integrity / reliability

**7. [opnsense] Silent-empty on API error in 3 read methods.**
`opnsense_engine.py` `get_dhcp_leases:781`, `get_dns_records:234`, `get_arp_table:831` don't check the `_request` ERROR envelope before returning `SUCCESS+[]` (401/timeout → looks like "no data"), and `_cache_live` then serves the bogus empty for 1h; `get_dhcp_leases(limit=0)` feeds the NetBox discovery sync. Sibling methods (`get_all_firewall_rules:164`, `get_nat_policies:322`) already classify it. Fix: add the same `status==ERROR` guard.

**8. [lm core] NetBox api routes swallow spoke `ERROR` into HTTP 200.**
`core/src/api.py` ~20 NetBox routes use `_unwrap_spoke` (`access.unwrap_spoke:112`) which strips the envelope but never checks `status`, so `{"status":"ERROR",…}` returns 200+error-body. Siblings `_spoke_payload_or_raise:562` / `_cppm_unwrap:2994` raise 502. Fix: ERROR-raising unwrap for NetBox.

**9. [lm core] api routes re-wrap 4xx/503 as 500 (missing `except HTTPException: raise`).**
`api.py` ~11 routes: `update_user:5969` (masks the 409 the Add-User modal needs), `assign_user_tenant:5907`, `provision_module:6488`, `add/update_firewall:2063/2087`, `install_module:5683`, `rename_spoke:5743`, `remove_user_tenant:5931`, `approve_spoke:1033`, tenants `5857/5873`. Fix: add `except HTTPException: raise` before each `except Exception`.

**10. [dns/dhcp] Two divergent implementations + ephemeral persistence.**
Sibling `/vscode/{dns,dhcp}` (LOAD_ROLE) and `lm/{dns,dhcp}` (standalone install) are entirely different code — different managers, error keys, ports, VERSION. Sibling dns uses `unbound-control local_data` (runtime-only → lost on reload); sibling dhcp uses `reservation-add` (runtime-only → lost on restart) and defaults `KEA_URL=:8000` (collides with hub; lm copy uses `:8001`). Sibling dhcp treats Kea result code 3 (EMPTY) as error (`dhcp_manager.py:26`) → empty server throws instead of `[]`. lm/dhcp `kea_manager.py:108` KeyErrors on a reservation missing `ip`. Fix: reconcile to one implementation; persist records/reservations; handle code 3; guard `r.get("ip")`.

**11. [ldap] Sync `python-ldap` blocks the event loop + connection leak.**
`ldap_spoke.py:54-111` calls `simple_bind_s/search_s/add_s/modify_s/passwd_s` directly in `async handle_command` (no `to_thread`) → slow slapd stalls heartbeats → hub disconnects the spoke; `get_status:130` binds fresh each poll. `_get_connection:16` never `unbind_s()` → FD/socket leak. Fix: `await asyncio.to_thread(...)`; try/finally unbind or pooled conn.

**12. [cppm] Param-blind cache.**
`spoke.py:141-143` caches `CPPM_GET_ACCESS_TRACKER`/`GET_DEVICE_DATABASE` by command name only; after `refresh_cache` primes defaults, a page-2/`status=` request returns the cached default slice. Fix: exclude paged/filtered cmds or key by `(cmd,limit,offset,status)`.

**13. [le] Renewal-loop lost-update race.**
`le_spoke.py:124-157` loads a separate `state`, `await acme_renew` (60s+), then `self._certs = state; save` — overwriting any concurrent `LE_ADD_TARGET`/`MARK_DISTRIBUTED` that mutated `self._certs` during the await. Fix: shared `asyncio.Lock` across loop + handlers, or in-place merge by key.

## P2 — robustness / hygiene / coverage

**14. [cppm] Test suite un-collectable.** `queries.py:2`/`spoke.py:3` bare imports vs `tests` package imports → `ModuleNotFoundError: client` aborts collection. `main.py:27` also calls nonexistent `queries.list_endpoints`. Fix: dual-import pattern (as `nw/src/nw_spoke.py:5`) or root `conftest.py`.

**15. [all 9] No runtime dep self-heal.** No entrypoint calls `dep_guard.ensure_requirements` (only in docs). A code-only auto-update crash-loops under `Restart=always`. Fix: add the stdlib block atop each entrypoint (mirror `pxmx/src/control_plane.py:25`).

**16. [installers] Soft `git pull` self-update.** cppm/ldap/le/nw/opnsense/netbox use plain `git pull` (or netbox re-clone) → stale/detached clone runs old code or crash-loops. Fix: `git fetch && git reset --hard origin/<branch>` + entrypoint-exists check (mirror bugfixer install.sh:51 / lm 7b4891f).

**17. [test infra] `core/pytest.ini` missing `asyncio_mode=auto`** + `requirements-dev.txt:7` pin drift (`<1.0` vs installed 1.2.0) → 30 false failures hiding real async regressions. Fix: add the setting + reconcile pin.

**18. [logging] INFO spam** — opnsense (worst: per-command/request/nat-probe/cache-hit `opn_spoke.py:124,127,191`, `opnsense_engine.py:30,66,313,337,356`), netbox/cppm/nw per-command. Demote to DEBUG (pxmx 7e4a8a6 / cs 6596d5c).

**19. [ldap] Non-atomic PEM write + key-perm window** `ldap_spoke.py:249` (`open("w")` truncate then chmod). Mirror le's `os.open(...,0o600)`+`os.replace`.

**20. [dns/dhcp] `--hub required` with no `auto` default** `dns/src/main.py:54`, `dhcp/src/main.py:54` → argparse crash if run standalone. Default to `os.getenv("HUB_URL") or "auto"`.
